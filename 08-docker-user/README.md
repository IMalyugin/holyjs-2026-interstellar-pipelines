## Перенос инструкции USER в sh-скрипты

### Основная идея

Вместо переключения пользователя в Dockerfile:
```dockerfile 
USER node
RUN some_shell
USER root
```

Запускаем весь Dockerfile от root, но для отдельных команд в самих sh-обертках запускаем пользовательский код от конкретного пользователя через `su`  

Код приведен в файле ci-node.sh
