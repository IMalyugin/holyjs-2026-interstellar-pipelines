## Перенос инструкции ENV в sh-скрипты

### Проблема

Каждая инструкция в dockerfile запускается в изолированном shell. Поэтому нельзя просто завести переменную окружения - она будет недоступна в следующих инструкциях.

Поэтому для dockerfile создана отдельная инструкция - ENV, которая прошивает переменную окружения в слой, делая ее доступной для следующих инструкций.

Но если мы выполняем конкретные sh-скрипты, например:
```dockerfile
RUN ci-tools install buildah
```

Иногда нужно иметь возможность устанавливать переменные окружения внутри данных скриптов, не вынося их наружу.


### Решение
1. Отдельным helper-ом `ci-env` пишем переменные окружения в .env файл
2. Считываем значения из .env файла в обертке для sh при помощи source

Код helper утилиты приведен в файле ci-env.sh
